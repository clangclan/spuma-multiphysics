# N₂O/IPA 상변화·반응 열유동 확장 및 초음속 검증

기준 소스: `40a86e96dcd3713d0ac0afc3b8b162188eb67624`. 구현·빌드·모든 실행 검증은 MAIN이 수행했고, 보조 에이전트는 수식·소스의 읽기 검토와 공개 자료 조사만 수행했다. 실제 R04 원본 케이스는 변경하지 않았다. 사용자 제공 반응기구·실험자료는 없으며 공개 CRECK 자료를 초기 비교 기준으로 사용했다.

## 판정

**실행 가능한 상변화·반응 열유동 HEM 솔버를 추가했다. 다만 고압 액체 주입부터 연소까지의 End-to-End 예측 솔버로 완성·검증됐다고 판정할 수 없다.** 최종 기본 캠페인의 18개 실행 중 16개가 각 검사 기준을 통과했고, 32/64셀 물질 접촉면 압력 정확도 검사는 모두 실패했다. 캠페인 전체의 `passed`는 `false`로 유지한다.

초음속에서 보존식, 상평형 음속, 점성·열전도·종 확산, 화학 source의 제한된 수치 정합성은 확인했다. 이 결과는 임의의 다상 충격파, 고압 액체 분무·점화·연소 불안정 또는 실제 형상의 예측 정확도를 보증하지 않는다. 최종 수치와 출처·소스 해시는 [기계 판독 결과](../results/reactive-phase-summary.json), 사용법은 [전용 README](../README.reactive-phase.ko.md)에 있다.

## 구현한 보존식과 열역학

새 실행 파일은 `bin/pintleReactiveFoam`, 열역학·화학 백엔드는 `lib/libpintleReactiveBackend.so`다. SPUMA의 메시·필드 입출력을 사용하고 유속·열역학·화학은 호스트에서 계산한다. 기존 세 재료 VOF 및 순수 기체 경로와 별도 소스로 구현했다.

화학종 s의 보존량은 다음과 같다.

\[
q_s=\alpha_g\rho_gY_{g,s}+\sum_{l\in s}\alpha_l\rho_l,\quad
\rho=\sum_s q_s,\quad Q=(q_1,\ldots,q_N,\rho\mathbf u,\mathcal E).
\]

각 액체는 순수 N₂O 또는 IPA이고 기체와 공통 `p,T,u`를 갖는다. 부피당 내부에너지는 \(E=\mathcal E-|\rho\mathbf u|^2/(2\rho)\)다. 셀마다 액체 질량, 기체 조성, 압력·온도를 다음 조건으로 복원한다.

\[
\sum_k m_k/\rho_k(p,T,Y_k)=1,\qquad \sum_k m_k e_k(p,T,Y_k)=E.
\]

공존하는 액상과 기상 성분은 \(\mu_l=\mu_{g,s}\)를 만족한다. 액체가 없는 경우 생성 안정성 부등식을, 기체가 없는 경우 가상 증기의 tangent-plane 조건을 검사한다. 여러 active set과 초기 추정으로 찾은 허용 후보 중 최대 엔트로피 상태를 선택한다. **찾지 못한 다른 해보다 엔트로피가 크다는 전역 보증은 없다.** 계면에너지·액상 혼합·용해·고체는 모델에 포함하지 않는다.

기·액의 표준 열역학 다항식 전체와 기준 압력을 비교해 생성에너지·엔트로피 기준의 동일성을 확인한다. 순수 액체 PR 근을 직접 선택하고 실제 EOS 압력 및 기·액 분기를 재검사한다. 음의 열용량·압축성, 비유한 값, 미지원 온도·압력 상태는 거부한다.

같은 에너지 기준에 기화 잠열과 화학 생성에너지가 이미 포함되므로 `Gamma*L` 또는 별도 `Qdot`를 추가하지 않는다. 기상 기준 반응률에는 기상 체적분율을 곱한다.

\[
\dot q_s=\alpha_g W_s\dot\omega_s,\qquad \dot{\mathcal E}_{\rm chem}=0.
\]

CVODE BDF의 각 RHS에서 보존 내부에너지로 flash를 풀고 그 상태에서 반응률을 계산한다. EOS 미분 과정이 바꾼 임시 기체 상태는 속도식 평가 직전에 복원한다. 비음수 제약과 최종 원소·총질량 검사를 적용한다. Newton의 미세한 음수 trial만 rate 평가 시 0으로 취급하며, 채택된 보존장을 사후 clipping하지 않는다. 부적합한 source 결과는 버리고 전체 유동 단계를 다시 시도한다.

## 초음속 수치 결합

공간 1차 HLL 유속을 모든 종·운동량·총에너지에 동일하게 적용한다. SSPRK2 유동 단계 앞뒤에 화학 반단계를 둔다. 평형 상분배에 대한 음속은 UV·화학퍼텐셜 제약의 Jacobian으로 구하며, 파속 상계에는 상분배를 고정한 음속의 1.1배를 사용한다. `0 < c_eq <= c_frozen`의 수치 검사를 통과해야 한다. 이는 모든 비선형 Riemann 문제에 대한 엄밀한 최대 신호속도 증명은 아니다.

셀 면적·체적과 `|u_n|+1.1*c_frozen`, 점성·열·종 확산 제한으로 시간 간격을 정한다. 화학 반단계 후와 RK 중간 상태에서도 CFL을 다시 검사한다. 실패하면 종·운동량·총에너지·상태를 모두 복원하고 `dt/2`로 재시도한다. 압력 바닥값으로 에너지를 덮어쓰지 않는다. 경계 유출입을 시간 적분해 전역 질량·원소·운동량·총에너지 수지를 별도로 검사한다.

Newtonian 응력의 운동량 유속과 같은 응력의 일을 에너지 유속에 넣고, Fourier 열전도 및 기상 종 확산 엔탈피도 포함했다. 공통 Fick 계수의 총 확산 질량 유속은 보정 속도로 0이 되게 한다. 비균일 격자에서는 `alpha_g*rho_g*D`의 면까지의 저항을 합산한다. 비이상 기체의 화학퍼텐셜 확산 인자는 미구현이므로 PR+Fick 조합은 차단한다. 일정한 공통 D는 검증용 근사이며 다성분 Maxwell–Stefan·열확산·압력확산을 대체하지 않는다.

최종 18개 실행에서 경계 수지를 보정한 전역 질량 상대 잔차 최대는 `3.97e-12`, 총에너지는 `1.51e-15`, 원소 수지는 `6.88e-12`, 운동량은 `5.27e-16`이다. 종 질량은 채택된 모든 최종 셀에서 비음수다. UV 에너지·부피 잔차는 설정값 `1e-9` 이내이고 화학퍼텐셜 무차원 잔차는 `1e-7` 이내다. 이러한 보존 결과가 물질 접촉면의 압력 정확도 실패를 없애지는 않는다.

반응 충격파에서는 미소 종 음수/허용오차 검사 때문에 7회의 시간 간격 축소가 발생했다. 이는 부적합한 시도를 복원한 기록이며 채택된 상태의 clipping으로 통과한 것이 아니다. 고온 화학 균일 4셀 시험은 약 37초, 저온 상변화·화학 4셀 시험은 약 77초, 반응 충격파 8셀 시험은 약 30초였다. 이번 실행시간은 현재 CPU 기준 구현의 비용을 보여주며, 대규모 GPU 성능 수치로 사용할 수 없다.

### 시간 간격 민감도와 기존 경로

고온 화학, 저온 상변화·화학, 반응 충격파에 대해 최대 시간 간격을 절반으로 한 추가 3개 실행이 모두 해당 검사 기준을 통과했다. 동일 종료시간에서 다음 차이를 확인했다. 반응 충격파의 실제 단계 수는 재시도 때문에 정확히 두 배가 아니다.

원시량과 종 질량분율의 차이는 `reactive-phase-summary.json/time_sensitivity`에 기록했다. 두 해의 비교만으로 Strang 분할의 점근적 2차 수렴이나 실제 반응 충격파 정확도가 증명되지는 않는다. 균일 source 사례는 공간 유속의 변화를 시험하지 않으므로 비균일 계면·반응의 결합 정확도에 대한 증거로 확대하지 않는다.

기존 경로의 13개 회귀 검사는 모두 통과했다. 이전 캠페인에서 사용한 바이너리·라이브러리 SHA-256도 동일하고 기존 추적 소스는 변경되지 않았다. 이번 확장은 기존 coldFoam의 수치 결과를 개선했다고 주장하지 않는다. 과거 legacy A/B의 비트 단위 차이와 수치 정책 통과 기록은 기존 초음속 보고서에 그대로 남아 있다.

## 접촉면 실패와 End-to-End 적용에 남은 문제

접촉면의 초기 압력·온도·속도는 같지만 조성과 IPA 액상량이 다르다. 보존량을 수치적으로 혼합한 뒤 비선형 EOS·상평형을 적용하면 같은 압력 상태가 유지되지 않는다. 이번 격자 세분화로 L1 오차는 줄었으나 peak는 약 6%로 남았다. 따라서 질량·에너지 보존만으로 다물질 초음속 정확도를 주장할 수 없다. 압력만 맞추는 총에너지 재설정도 해결책으로 사용하지 않았다.

| P1 | 고차 해상도·복잡 형상·실제 입출구 경계 | 비직교·skew 보정, 특성 기반 경계, 노즐·주입기·충격파/경계층 시험 |
| P2 | CPU 화학 비용, 대규모 저장·메모리, GPU·MPI | 현재 413종 기준 경로와 수치 동등성, 분산 교환·전체 성능·정밀도 검증 |

HEM은 열·속도·상평형 완화시간을 0으로 둔다. 초음속 유동에서 화학·기화·상간 열교환 시간이 대류/음향 시간과 비슷하면 실제 비평형 현상을 잃는다. 따라서 현재 시험의 통과와 관계없이, 목표 장치의 시간척도 및 실험 자료 없이 전체 모델 선택을 정당화할 수 없다.

## 반응·열역학 자료의 출처와 적용 한계

공식 [CRECK 고정 버전 README](https://github.com/CRECKMODELING/Kinetic-Mechanisms/blob/640d5b492d849e33c08bfbbd9d3de25dd074c9a4/Gas-Phase/Diesel-Biodiesel/Soot-NOx/TOT_HT_NOX_413_14922/README.md)는 413종·14,922반응의 고온 C₁–C₁₆+NOx 기구를 설명한다. [동일 revision의 CHEMKIN 원본](https://raw.githubusercontent.com/CRECKMODELING/Kinetic-Mechanisms/640d5b492d849e33c08bfbbd9d3de25dd074c9a4/Gas-Phase/Diesel-Biodiesel/Soot-NOx/TOT_HT_NOX_413_14922/kinetics.CHEMKIN.CKI)에 `IC3H7OH`와 `N2O`가 함께 있다. 두 물질의 포함은 목표 추진계에 대한 검증과 별개다.

[원본 열역학 자료](https://raw.githubusercontent.com/CRECKMODELING/Kinetic-Mechanisms/640d5b492d849e33c08bfbbd9d3de25dd074c9a4/Gas-Phase/Diesel-Biodiesel/Soot-NOx/TOT_HT_NOX_413_14922/thermo.CHEMKIN.CKT)의 IPA 300–3500 K, N₂O 200–3500 K 범위는 기상 다항식 범위다. 저온 냉유동용 N₂/O₂/N₂O 이상기체 열용량은 CoolProp 6.7, IPA는 설치된 SPUMA `iC3H8O.C`의 이상 증기 열용량 상관식으로 확장하고 원래 계수와 h/s/Cp를 연결했다. 이 보간·연결은 액상·저온 반응 실험 검증을 의미하지 않는다. PR 임계상수 및 각 확장 오차는 생성 manifest에 기록된다.

[Capriolo 등, Fuel 287 (2021), 119499의 원저자 기관 기록](https://portal.research.lu.se/en/publications/high-temperature-oxidation-of-propanol-isomers-in-the-mixtures-wi/)은 propanol 1–10 ppm, N₂O 10 ppm, Ar의 극희석 반사충격파 조건(1700–3200 K, 2–3 bar)에서 산소원자 시간 이력을 비교한다. 2000 K 아래 예측의 어려움도 보고한다. 논문의 POLIMI 버전을 현재 다운로드한 413종 버전과 동일하다고 간주하지 않는다. 이 실험 범위로부터 고압 액체 flashing·분무·점화지연·연소 안정성이 검증됐다고 추론할 수 없다.

원본 transport에는 596개 종의 중복 레코드와 32개 종의 값 충돌이 있었다. 최초 엄격 변환의 실패를 보존하고, 후속 변환에서 첫 transport 항목 선택 정책과 충돌 목록을 명시했다. 전체 413종·14,922반응을 유지했다. 현재 유동 솔버의 지정 상수 수송계수에는 해당 transport 라이브러리 값을 자동 적용하지 않는다. 원본과 생성된 전체 반응기구는 로컬 연구 자료로 두고 배포 소스에 포함하지 않았다.

## 재현·증거 보관

최종 열역학 검사는 `results/reactive-thermo-validation-v7.json`, 실행 보호·재시작 검사는 `cases/reactive-runtime-v9`, 기본 유동은 `cases/reactive-campaign-final`, 시간 간격 비교는 `cases/reactive-campaign-halfdt`에 있다. 모든 실행 디렉터리에 입력 정의·해시·종료장·로그를 보관한다. 작은 통합 결과와 해시는 `results/reactive-phase-summary.json`에 수록한다. 재실행 명령·기구 준비·환경 고정 목록은 전용 README를 따른다.

개발 중 원본 transport 변환 실패, 잘못된 고압 dilute 조합의 차단, 300 K 경계에서 열역학 도메인을 벗어난 확산 시험 실패, 32/64셀 접촉면 실패를 삭제하지 않았다. 확산 시험은 물성 바닥에서 떨어진 500 K로 재설계하고 계수 0 대조군을 함께 실행했다. runtime-v8의 음수 종 검사는 실제 거부가 정상 작동했으나 검사기가 다른 오류 문자열을 기대해 실패했으며, 메시지 기대값만 수정한 v9에서 통과했다. 접촉면의 1% 기준이나 보존·양성 기준은 완화하지 않았다.
