# ReactiveFoam GPU 표면장력·flashing 통합 검증

GPU 유동 경로에 표면장력과 flashing을 연결했다. 그러나 **정적 액적의 기생 유속
수렴 시험에 실패하여 물리 정확도 승인은 보류**한다. 이 변경은 Draft PR 검토 대상이며,
완성된 액주·액막 분열 솔버라는 의미로 main에 병합하지 않는다.

## 구현 범위

독립 액체 질량 수송, 접촉면을 보존하는 HLLC 유량, GPU 계면 구배·법선·곡률,
보존적 모세관 응력/에너지 유량, 모세관 CFL을 연결했다. 총에너지는 벌크 내부에너지,
운동에너지, `sigma*|grad(c)|`를 포함한다. GPU UV 복원은 곡률에 따른 기체·액체 압력차를
밀도·에너지·화학퍼텐셜에 반영하고, 표면에너지와 상분율을 외부 반복으로 결합한다.
상변화가 액체량을 바꾸어도 화학종·운동량·총에너지는 유지한다.

순수 액체에 미량의 공기가 유입되는 상태에서는 기존 후보 탐색만으로 해를 놓쳤다.
기존의 경계 전용 세부 탐색을 GPU capillary API에도 허용하여 포착한 656개 실패 입력을
모두 복원했다. CPU flash 대체, 질량 clipping, 잔차 기준 완화는 사용하지 않았다.

WALE 부분 엔탈피 준비에서는 거의 순수한 액체의 `총 N₂O−액체 N₂O` 뺄셈이
미량 증기의 유효 숫자를 잃는 문제도 수정했다. 상 복원이 보존한 기체 질량으로부터
더 안정적인 차를 선택하고 두 분해가 FP64 roundoff 범위 안에서만 일치하는지 검사한다.
기체 질량을 고의로 바꾼 상태는 거부한다.

표면장력을 끄면 추가 계면 메모리·커널은 0이고 기존 경로의 보존장과 물리 해시는 동일하다.
RK1 상변화 이후 GPU 상태 교체, 실패 스텝 rollback, 추가 액체 질량 체크포인트를 지원한다.

## 실제 GPU 실행

RTX 5080 / sm_120, FP64, CUDA 수송·UV, `closureCpuFallback false`를 사용했다.
작은 3D 케이스 9개는 off 두 구성, 평면 계면, 구형 액적 3개 메시, 파, 변형 액적,
flashing 구형 액적이다. [v7 실제 솔버 결과](../results/capillary-integration-20260923/solver-validation-v7.json)와
[flash 결과](../results/capillary-integration-20260923/flash-validation-v7.json)에 로그·실행 바이너리 해시를 남겼다.

- 평면: 60 ns 동안 최대 속도 약 `1.9e-14 m/s`, 질량·총에너지 drift 0.
- flashing: 4스텝, GPU 상태 복원 81,920/81,920 성공, flash 후보 152,360,
  CPU fallback/device failure 0. 액체량은 약 `3.91e-9 kg` 변했다.
- flashing 총 화학종 drift 최대 `7.54e-20 kg`, 운동량 drift `1.95e-22 kg m/s`,
  벌크·표면 총에너지 drift `8.88e-16 J`.
- 같은 시간 분할을 사용하는 재시작과 off 생략/false 보존장은 비트 단위로 일치했다.
  σ를 변경한 재시작은 물리 모델 해시 검사로 거부했다.

최종 빌드의 [열역학 집중 시험](../results/capillary-integration-20260923/thermo-focused-final.json)
20개와 [기존 선택·재시작 회귀](../results/capillary-integration-20260923/physics-switches.json)
35개가 통과했다. CPU/CUDA 공개 수송 API에서도 모세관→WALE→종 혼합 설정,
전역 보존, RK1 갱신과 RK2 결합을 확인했다.

이전에 미량 기상 엔탈피 검사로 실패한 4,096셀 [전체 물리 조합](../results/capillary-integration-20260923/full-physics-v8.json)은
최종 빌드에서 60 ns, 4스텝, 재시도 0으로 완료했다. 점성·열전도·WALE 열/종 혼합·
표면장력·flashing을 모두 켰고 GPU 복원 98,304/98,304 성공, CPU fallback/device failure 0이었다.
총에너지 drift는 `8.88e-16 J`였다.

256,000셀 충돌 분사 메시에서는 점성, 열전도, WALE 운동량·열·종 혼합,
표면장력, 상평형을 모두 켜고 각 환경 2스텝을 수행했다.
고체·승화·연소는 없으며 PR 분자 확산은 지원하지 않아 껐다.

액막이 분열하는 전체 계산이 아니다. [상세 계측](../results/capillary-integration-20260923/impingement-256k.json).

## 통과하지 못한 물리 정확도 기준

반경 1 mm, σ=0.01 N/m 정적 액적을 16³/24³/32³ 메시에서 60 ns 계산한 최대 기생 속도는
`5.02e-5 / 8.34e-5 / 1.16e-4 m/s`였다. 세분화할수록 증가하므로 수렴 기준에 실패했다.
평균 Laplace 압력차와 전역 에너지 보존만으로 이 문제를 통과 처리하지 않았다.
단순 응력 보간 변경과 계면 기하만 평활화하는 방법도 조사했지만 수정으로 채택하지 않았다.
[독립 진단과 필요한 후속 이산화](../docs/spray-physics/capillary-static-balance-review.md)를 참고한다.

파·액적 진동은 초기 응답만 실행했으며 주기/감쇠 정확도에 충분한 시간 길이가 아니다.
PLIC/height-function 기반 날카로운 계면 수송, 액주 pinch-off, 액적 크기 분포 정확도를 주장하지 않는다.

## 사용·재현

[설정과 모델 범위](../docs/spray-physics/capillary-flashing.ko.md)에 입력 예와 재현 도구를 기록했다.
σ는 상수이며 온도 의존 표면 엔트로피·Marangoni 모델은 아니다.
계면·응력·UV 복원은 GPU지만 WALE 부분 엔탈피 준비와 실행 제어·파일 입출력은 호스트다.
각 증거 JSON에 해당 실행의 라이브러리 해시가 있으므로 서로 다른 개발 시점의 바이너리를 혼동하지 않는다.
