# 다상 해석 검토 반영 — 2026-09-11

참조한 「다상 해석 검토」의 지적을 실제 소스와 실행 결과로 확인하고, PR 열역학 항등식·비혼합 접촉면 폐쇄식·화학 Jacobian을 수정했다. 코딩·빌드·모든 실행 검증은 MAIN이 수행했고, 보조 에이전트는 수학·소스·문헌을 읽기 전용으로 검토했다. 원본 R04 케이스는 수정하지 않았다.

**비반응 접촉면의 압력 보존은 개선됐지만, 고압 N₂O/IPA 주입부터 연소·분무까지의 검증된 단일 모델은 아직 아니다.** 기본 HEM과 새 비혼합 환경 모드는 물리 가정과 지원 기능이 다르다. 기준 EOS 대비 물성 편차도 크게 남는다.

실행 판정·실패 항목·소스 및 바이너리 해시는 [전체 결과 요약](../results/multiphase-review-summary.json)에 기록했다.

## 1. 기존 PR 열역학 수정

`pintlePengRobinsonGasI.H`의 H/E/S를 동일한 PR departure 식으로 맞췄다. 반올림한 `2.414/0.414/2.828` 대신 정확한 √2 조합을 사용하며, 고온에서 `sqrt(alpha)`가 버리던 `1+κ(1−√Tr)`의 부호를 보존한다. Cv departure의 중복 `−R`도 제거했다. E는 순수 잔여 내부에너지, H는 여기에 `RT(Z−1)`를 더한 형태다.

새 `pintlePrIdentityCheck`는 실제 컴파일된 CPU/GPU 템플릿과 등록된 hConst 내부에너지 래퍼를 검사한다. 기존 PR 함수를 그대로 정답으로 삼지 않고, 5점 차분·Maxwell 관계·departure 항등식을 사용한다. 기존 `thermoCheck`의 값 비교와 이 독립 미분 검사는 역할이 다르다.

이전 버전의 `p/T`를 새 버전에서 읽으면 새 caloric 모델로 에너지를 재해석한다. **이전 절대 내부에너지를 그대로 보존하는 자동 모델 이관은 아니다.** 동일 버전 재시작 검사는 아래 별도 결과로 구분한다.

### 기존 VOF 경로의 재시작 결함 수정

같은 모델의 8단계 연속 실행과 4+4 재시작을 비교하면서, PR 식 수정 전에도 존재했던 결함을 재현했다. 밀도와 운동에너지 K의 `oldTime()` 이력이 첫 갱신 뒤에 만들어져 재시작 첫 단계에서 시간 미분이 달라졌다. 또한 압력 corrector의 선형 보정 후 상별 밀도는 p/T에서 새로 계산한 EOS 밀도와 구별되는 반복 상태다.

첫 시간 증가 전에 혼합·상별 밀도, K 및 시간 미분에 쓰는 필드 이력을 준비한다. 새 checkpoint에는 `pintleRhoState.<phase>`와 `pintleThermoState`를 함께 기록하고, 재시작 시 PR caloric 버전과 상별 열역학 사전 해시를 확인한다. checkpoint의 상별 밀도가 빠지거나 열역학 사전이 달라진 입력은 거부한다. 새 checkpoint가 없는 기존 입력은 p/T에서 시작한다.

## 2. 두 비혼합 환경의 기계적 평형 모드

`constant/reactiveProperties`에서 `closure mechanicalEquilibrium;`를 선택한다. 같은 셀에 공간적으로 분리된 환경 A/B를 유지하고 공통 p/U, 서로 다른 T/조성을 허용한다. 각 환경 내부는 기존 UV HEM flash를 사용한다. 저장 변수는 환경별 N개 화학종 질량, 공통 운동량·총에너지, 두 체적분율로 총 `2N+6`개다.

환경 체적분율 α, β와 환경의 평형 체적탄성률 `Bᵣ=ρᵣcᵣ²`에 대해 다음 식을 사용한다.

\[
\partial_t\alpha+\nabla\cdot(\alpha\mathbf u)
=(\alpha+K)\nabla\cdot\mathbf u,
\quad
K=\frac{\alpha\beta(B_B-B_A)}{\alpha B_B+\beta B_A},
\qquad
\frac1{\rho c^2}=\frac\alpha{B_A}+\frac\beta{B_B}.
\]

β에는 `(β−K) div(u)`를 사용한다. 두 분율을 따로 수송해 `1−α`의 부동소수점 상쇄로 극소량 환경이 사라지는 문제를 피한다. 모든 환경 재고·총에너지·분율에는 같은 HLL 혼합 계수를 적용하고, 발산에는 같은 HLL 중간 상태의 면 속도를 사용한다.

일정 총 내부에너지에서 환경 사이 에너지 분할 하나를 풀어 두 압력을 맞춘다. 에너지가 음수가 될 수 있는 생성에너지 기준을 허용한다. 작은 환경의 에너지를 직접 미지수로 삼아 `total−majority` 상쇄를 줄인다. T/p 경계에서는 유효한 방향의 한쪽 차분을 허용한다. 출력 압력을 맞추기 위해 총에너지를 덮어쓰거나 화학종을 잘라내지 않는다.

### 검증과 남은 수치 확산

실제 PR N₂O/IPA 접촉면을 M=0,+2,−2와 16/32/64셀에서 계산했다. 32셀에서는 양방향 1.2 도메인 길이의 주기 이동도 검사했다. 모든 접촉면에서 압력·속도·질량·운동량·에너지·환경 재고 보존 조건이 충족됐다. 압력의 전 단계 최대 상대오차는 약 **7.9×10⁻¹⁰ 이하**다.

압력만 일정하게 남은 정지 해가 이동 시험을 통과하지 못하도록, 분율의 Fourier 위상·이동된 정확한 셀 평균 프로파일·환경 재고와 체적의 비례 관계도 확인한다. 이동 위상은 이동 거리로 정규화한 **1.5% 속도 오차 기준**을 사용한다. 고정 위상각 제한은 이동 시간이 길어질수록 다른 속도 기준이 되므로 최종 분석에서 이 정의를 명시하고 기존 캠페인·원시장을 보존했다.

**16셀의 M=±2는 이동 속도 기준에 미달한다.** 32·64셀에서는 통과하고 L1 분율 오차가 격자 세분화에 따라 감소한다. HLL의 계면 확산이 남아 있으므로 날카로운 계면 재현이나 공간 고차 정확도를 주장하지 않는다. 최종 재분석 캠페인의 결과는 17/19 통과이며, 두 실패는 이 거친 격자의 속도 기준이다.

| 계면 이동 속도 상대오차 | 2.538% | 0.6377% | 0.1596% |
| 환경 분율 L1 오차 | 0.08175 | 0.07401 | 0.04989 |

1.2 길이 이동 후 32셀 분율 L1 오차는 0.2807로 커진다. 긴 이동 동안 압력 보존이 유지돼도 상당한 계면 확산이 축적된다는 뜻이다.

이 모드는 **비반응·비점성·환경 사이 열 및 질량 교환 없음**에 한정한다. 화학·열전도·질량 확산·점성을 함께 켜면 거부하며, 고정 원시 상태 경계도 아직 지원하지 않는다. 혼합 출력 T는 진단용 체적 평균이다. 두 환경 사이 열평형, 액체 혼합·용해 또는 화학 반응을 해결한 것으로 해석하면 안 된다.

기본 HEM의 기존 물질 접촉면은 그대로 실패한다. 같은 길이의 M=2 시험에서 32/64셀 최대 압력 오차는 6.488% / 6.249%다. HEM을 비혼합 계면 모델로 바꾸지 않고 이 결과를 숨기지도 않았다. 두 폐쇄식의 보존량·식별값이 다른 재시작은 거부한다.

## 3. 실제 413종 기구의 구조화 Jacobian

활성 상 집합이 고정된 구간에서 `z=(ln p,ln T,활성 액상 분율)`과 열역학 잔차 `F(q,z)=0`를 사용한다.

\[
J=f_q-f_z\,\operatorname{solve}(F_z,F_q).
\]

고정 z에서 화학종을 섭동할 때 전체 UV flash를 다시 풀지 않는다. 잔차와 반응률의 차분을 공유하며 열역학 보정의 차원은 최대 4다. 실제 CVODE Jacobian 콜백에 이 행렬을 전달한다. 상 출현·소멸 경계, 나쁜 조건수, 유효하지 않은 probe와 음의 Newton 시험 상태에서는 전체 RHS 차분을 사용한다. 엄격한 비음수 검사를 만족하지 못한 적분은 원래 입력에서 기준 적분기로 다시 수행하며, 실패한 결과를 clipping해서 채택하지 않는다.

독립 Cantera 이상기체 미분으로 구성한 실제 413×413 행렬과의 상대차는 **4.47×10⁻¹⁰**이다. 액상 존재·부재 및 고정 액상 질량의 Jv를 방향 차분으로 확인하고, 상 경계에서 fallback이 실행되는지도 검사했다.

| 실제 적분 비교 | 전체 RHS 차분 | 구조화 Jacobian | 관측 배율 |
|---|---:|---:|---:|
| 고온 기상 반응 | 7.953 s / 51,938 UV 호출 | 5.416 s / 26,660 UV 호출 | 1.47× |
| 저압 액상·반응 결합 | 6.678 s / 1,349 UV 호출 | 2.606 s / 528 UV 호출 | 2.56× |

고온 최종 온도 상대차는 1.83×10⁻⁹, 질량분율 최대차는 7.14×10⁻¹⁰이다. 구조화 결과와 동일 기구 ReactorNet의 온도 상대차는 3.12×10⁻¹¹이다. 액상 결합 두 적분의 질량분율 최대차는 1.10×10⁻¹²이다. 모두 비음수 및 원소 수지 검사를 통과했다.

이는 **두 source 문제에서 관측한 단일 CPU 실행 비교**다. 전체 CFD, GPU 또는 고압 연소의 일반 가속률이 아니다. 고온 시험의 58회 Jacobian 중 46회가 강건성 fallback을 사용했다. 현재 선형계는 밀집 직접법이며 Woodbury 선형해법·희소 전처리·GMRES·GPU 화학은 구현하지 않았다.

## 4. 기준 EOS 대조에서 드러난 물성 한계

CoolProp 6.7.0 HEOS N₂O를 독립 기준으로 밀도·Cp·Cv·음속·포화압·잠열을 비교했다. CoolProp은 N₂O의 기준 EOS로 Lemmon–Span 식을 명시한다. [CoolProp 공식 N₂O 문서](https://coolprop.org/fluid_properties/fluids/NitrousOxide.html)

| 조건 | PR−기준 / 기준 |
|---|---:|
| 압축 액체, 283.137492 K·5 MPa: Cp | +15.18% |
| 같은 상태의 액체 음속 | −15.98% |
| 300 K 포화 액체: 밀도 / Cp | −10.30% / +40.17% |
| 305 K: 포화압 / 잠열 | +0.341% / −15.48% |
| 305 K 포화 액체 Cp | +49.57% |

포화 비교는 같은 T에서 **각 EOS 자체의 포화압력**을 사용한다. 액체·증기의 음속은 각 상의 값이며 HEM 두 상 혼합물의 음속 비교가 아니다. 포화압이 가깝다는 사실만으로 잠열·음속·열용량까지 검증됐다고 할 수 없다. 결과 파일의 `validated_operating_range`는 `null`로 유지했다. 이 대조는 N₂O 순수 물성에 대한 것으로 IPA 및 혼합액 정밀 물성까지 검증하지 않았다.

사용한 공개 propanol/N₂O 실험은 propanol 1–10 ppm, N₂O 10 ppm, Ar 희석, 2–3 bar, 1700–3200 K의 원자 산소 시간 이력이며 2000 K 아래 기구 예측의 어려움을 보고한다. 이 조건은 고압 액체 분무·점화지연·연소 안정성 검증과 다르다. 논문에서 비교한 POLIMI 기구가 내려받은 현재 413종 버전과 동일하다는 근거도 없다. [원저자 기관의 논문 기록](https://portal.research.lu.se/en/publications/high-temperature-oxidation-of-propanol-isomers-in-the-mixtures-wi/)

임의 완화시간·액적 직경·기구 보정계수를 넣어 이러한 공백을 메우지 않았다. 유한속도 상변화, 기포 성장, 상간 슬립·열전달, 분열·합체, 계면 면적 및 고압 반응·혼합액 물성은 후속 모델과 독립 자료가 필요하다.

## 5. 초음속 적용 범위

갱신한 HEM 실행은 M=2 균일장·두 상 음향파·순수 N₂ 충격파·균일 화학·저압 상변화/화학 source·M=2.5 기상 반응 충격파의 6개 사례를 통과했다. 접촉면 두 사례는 앞서 밝힌 이유로 실패한다. 입력 거부·재시작·비균일 격자 확산 저항·기구 식별 검사는 10항목을 통과했다.

기상 반응 충격파는 액상 없는 8셀·2 μs, 상변화/화학 결합은 균일 4셀·0.1 μs다. 이 시험을 다상 충격파–계면–증발–반응의 공간 결합 검증으로 확대하지 않는다. 새 환경 모드의 Wood 음속·접촉면 시험 역시 강한 다상 충격파의 비보존 경로·엔트로피 조건이나 유한속도 완화의 검증이 아니다.
