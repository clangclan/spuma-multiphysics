# 표면장력·WALE 리뷰 반영 결과

리뷰의 우선 과제인 **WALE PR 엔탈피 GPU 이관과 실제 면 유량의 정적 잔차 분해를 완료**했다.
면 color·모세관 일률의 정합성도 수정했다. 그러나 **정적 액적 기생 유속의 메시 수렴은
여전히 실패**한다. 완성된 분열 솔버로 승인하거나 main에 병합하지 않고 Draft PR #6을 갱신한다.

검토 자료는 `SPUMA_capillary_WALE_review_20260923.zip`과 참조 대화 「GPU 정적 액적 해법」이다.
첨부 코드는 CPU 검증을 마친 제안임을 확인하고, 생산 코드와 별도로 대조했다.
[패키지 해시·검토 head](../results/capillary-review-20260923/review-provenance.json)를 기록했다.

## 구현

- 단일 액체 모세관 경로의 내부 셀 엔탈피를 기존 GPU PR `phasePartials()`로 평가한다.
  기상·액상 압력과 실제 상별 질량으로 total-species 엔탈피를 구성한다. 미량 증기의
  뺄셈 정밀도, 상 밀도·체적 및 `sum(q*h)=rho*e+p_g*alpha_g+p_l*alpha_l` 검사를 유지한다.
  종 엔탈피에 표면에너지를 더하거나 이상기체로 대체하지 않는다.
- 수송 핸들이 PR 모델과 GPU Cp/H 작업 공간을 소유한다. RK 입력·열역학·기하·경계
  버전을 검사하고 모든 셀이 성공해야 임시 물성을 활성 버퍼에 반영한다.
  재시도·기하 갱신 뒤의 오래된 Cp/H, 장치 모델 설치 후 호스트 물성 업로드,
  열 혼합 전용 구성의 H 요청을 거부한다. 열 혼합만 켜면 Q/H 임시 배열을 할당하지 않는다.
- 면 color는 기하와 압력 복원에 같은 `ownerWeight`를 사용한다. 모세관 traction의
  일률은 법선 성분이 HLLC 접촉 속도인 하나의 면 속도로 계산한다. 공유 면의 양쪽 셀은
  반대 부호의 같은 운동량·에너지 유량을 받는다.

고정 경계의 초기 엔탈피, 사전 설정·입출력, UV 외부 반복 제어와 배열 포장은 호스트에 남는다.
표면장력 OFF의 기존 WALE 물성 경로는 유지했다. GPU 물성/flash 실패의 CPU 대체는 없다.
PLIC/HF 계면 수송이나 새로운 압력–응력 연산자를 이번 수정으로 구현했다고 주장하지 않는다.

  `3.93e-14`, Cp 비트 일치. 순수 기상/액상·0농도 종·변조한 질량 거부도 확인했다.
  656개는 한 계산의 관련 상태/재시도이며 독립적인 물리 검증 656건은 아니다.
  재현 입력은 [압축 회귀 데이터](../tests/data/README.md)에 포함했다.

  [CPU/CUDA 면 유량 시험](../results/capillary-review-20260923/face-tests.json)도 통과했다.
- [4,096셀 전체 물리](../results/capillary-review-20260923/full-physics-checkpoint-gpu-pr.json):
  60 ns까지 4스텝, 재시도 0. GPU PR 물성 86,016셀 평가, 커널 42회, 실패 0.
  내부 셀 호스트 엔탈피 평가·호스트 물성 시간은 0이다. 점성·열전도·WALE 열/종 혼합·
  표면장력·flashing을 켰고 고체·승화·연소·PR 분자 확산은 껐다.
- [전체 물리 재시작](../results/capillary-review-20260923/full-physics-restart.json)은 연속 실행의
  최종 보존장과 비트 단위 일치했다. 동결상 열 혼합은
  [실제 솔버](../results/capillary-review-20260923/frozen-heat-only.json)에서 통과했고,
  아직 허용하지 않는 동결상 종 혼합은 기존처럼 명시적으로 거부했다.

비교 시험은 원본 time=0 체크포인트를 `initialization conserved`로 읽었다.
이미 솔버가 작성한 초기장을 다시 `primitive`로 해석하면 곡률 열역학 때문에 초기 보존장이
달라짐을 발견해, 그 중간 시험은 비교에서 제외했다. 채택한 작은 시험들은
[초기 보존장 일치](../results/capillary-review-20260923/solver-status.json), 전체 물리 시험은
[초기 체크포인트 일치](../results/capillary-review-20260923/full-physics-initial-parity.json)를 확인했다.

나머지 0회도 기존과 같다. 최대 총에너지 상대 잔차는 각각 `1.73e-13`, `1.01e-14`다.
두 환경 모두 CPU flash fallback·GPU flash failure·GPU 물성 실패가 0이고,

물성 시간은 포장·장치 호출 대기를 포함하며 이미 수송/CFL 시간 안에 들어 있다.
표의 스텝 시간에는 초기화·체크포인트 쓰기가 포함되지 않는다. 일률 수정과 GPU 이관을
합친 짧은 관측이며, 단독 커널 가속률이나 발달한 충돌 분열의 성능 예측값은 아니다.

## 정적 액적: 원인 분리와 남은 실패

생산 기하·면 유량을 직접 호출하는 시간 0 진단에서 **정확한 구면 곡률을 넣어도**
16³/24³/32³의 최대 잔류 가속도가 `864/1374/1894 m/s²`다.
48³/64³에서는 `3929/6788 m/s²`로 계속 증가한다. 이 진단의 밀도·음속·에너지는
연산자 분리용 합성 입력이며 실제 열역학 솔버 결과와 구분한다.
샘플링을 8³→32³으로 바꿔도 앞 세 메시에서 `863/1371/1879 m/s²`로 거의 그대로다.
정확 곡률에서 질량 유량과 Riemann 압력 RHS는 0인데 최종 운동량 RHS는 남는다.
전역 운동량 보존만으로 셀별 압력–응력 균형을 보장할 수 없음을 확인했다.

동일한 초기 보존장으로 실행한 실제 솔버의 60 ns 최대 기생 유속은
`5.02e-5 / 8.34e-5 / 1.16e-4 m/s`, 체적 가중 L2 유속은
`6.60e-6 / 9.57e-6 / 1.23e-5 m/s`다. 수정 전과 사실상 같으며 세분화 수렴에 실패한다.
새 검증기는 비교 시간·물리 조건·격자가 다르거나 최대/L2 유속이 감소하지 않으면
`--require-static-convergence`에서 종료 코드 2를 반환한다.
[원시 진단](../results/capillary-review-20260923/face-decomposition.json),
[실제 솔버 결과](../results/capillary-review-20260923/solver-validation.json),
[이산 균형 검토](../docs/spray-physics/capillary-static-balance-review.md)를 참고한다.

후속 과제는 동일 계면 기하에서 압력·traction·표면에너지 일을 함께 정의하는 면 연산자다.
정확 곡률에서도 실패하므로 HF 함수만 교체하거나 응력 복원 항을 삭제하지 않았다.
장시간 모세관파·액적 진동과 1차 분열 정확도는 미검증이다. 현재 mm 크기 시험에서
30 ns 고정 스텝을 가정해도 두 진동 주기는 약 145만~209만 스텝이다.
정적 기준이 실패한 상태에서 그 대규모 계산을 시작하지 않았다.
